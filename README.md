# Trabalho Prático Estrutura de Dados 2 - Indice Remissivo


|Requisitos: 
- Mingw
- Editor de texto

```bash
# No windows

mingw32-make

# Depois rode com o exe criado

./index_remissivo
```
```bash
# No linux
make

# Depois rode com o exe criado

./indice
```

e então é so utilizar o menu para o seu indice remissivo!
